# Learn It

Пять скиллов для самостоятельного обучения с сохранением цели, плана, попыток и точного места остановки между занятиями.

[English README](README.md) · [Лицензия MIT](LICENSE)

| Скилл | Пример запроса | Результат |
| --- | --- | --- |
| `learn-start` | `$learn-start Хочу изучить теорию вероятностей` | Интервью, диагностика, источники, план и файлы курса |
| `learn-progress` | `$learn-progress Где мы остановились?` | Краткий обзор результатов, пробелов и следующего шага без изменения курса |
| `learn-next` | `$learn-next Продолжим обучение` | Возврат к незавершённому заданию или подготовка следующей темы |
| `learn-test` | `$learn-test Проверь меня по изученному` | Задания, оценка реальных ответов и учёт подсказок |
| `learn-review` | `$learn-review Сделай HTML-отчёт об обучении` | Красивый автономный отчёт: все темы, история, динамика, рост и повторения |

Инструкции и названия в интерфейсе написаны на английском. Занятия и пояснения в отчёте могут идти на языке пользователя. Скиллы также могут выбираться по смыслу запроса. Они не работают в фоне.

## Как устроен курс

Каждый курс хранится в отдельной папке. `GOAL.md` задаёт цель, `PROFILE.md` — исходный уровень и ограничения, `PLAN.md` — маршрут и предпосылки, `SOURCES.md` — материалы. `RESUME.md` сохраняет точное место остановки, `state.json` — структурированный прогресс. Материалы разделов находятся в `sections/`, история — в `sessions/`, проверки — в `assessments/`, HTML-отчёты — в `reports/`.

Пройденный материал, самостоятельное применение и удержание после перерыва учитываются отдельно. Решение с подсказкой остаётся решением с подсказкой; пропуск темы не становится успешной проверкой. Старые Markdown-проекты поддерживаются без сброса истории. Первый раздел готовится подробно, следующие раскрываются по мере продвижения.

## Установка в Codex

Клонируйте репозиторий и скопируйте все пять папок из `skills/` в `~/.agents/skills/`. Устанавливайте комплект целиком: общий контракт и валидатор находятся в `learn-start`. Если одноимённые папки уже существуют, сначала сравните версии.

Расположение и обнаружение скиллов описаны в [официальном руководстве OpenAI](https://learn.chatgpt.com/docs/build-skills). Если новый скилл не появился, перезапустите Codex. Этот репозиторий содержит папки скиллов для локальной установки.

Для Python-скриптов нужен Python 3.10+, сторонние библиотеки не требуются. Интервью, обучение, подбор источников и оценку открытых ответов выполняет агент.

## HTML-отчёты

В папке курса попросите `$learn-review` подготовить отчёт. Он покажет все темы, текущую точку, что ещё предстоит пройти, историю попыток, помощь, ошибки и запланированные повторения. Отчёт работает без интернета, адаптируется к узкому экрану и позволяет раскрывать разделы.

Для проекта со `state.json` можно запустить генератор из корня репозитория:

```sh
python skills/learn-review/scripts/render_review.py /path/to/course --output /path/to/course/reports/review.html --as-of 2026-11-05
```

Укажите фактическую локальную дату пользователя. Без `--as-of` повторения отображаются без пометки о просрочке. Дата ограничивает попытки, но не восстанавливает прошлое состояние учебного плана. Выбирайте новое имя для каждого отчёта. Скрипт создаёт визуальную основу; скилл читает исходные попытки и добавляет содержательный вывод. Старый Markdown-курс агент анализирует напрямую, без миграции.

График показывает накопление результатов с самостоятельными успешными попытками. Его рост сам по себе не доказывает улучшения знаний. Скилл проверяет сопоставимость задач, подсказки и критерии оценки. Если данных недостаточно, отчёт прямо это сообщает. Общая вероятность освоения предмета не вычисляется. Отчёты сохраняются локально; публикация требует отдельного запроса.

Для просмотра оформления на явно вымышленных данных выберите новую папку:

```sh
python examples/make_demo.py /path/to/new-demo
```

Откройте `reports/review.html` внутри неё. Пример содержит пройденную, текущую, запланированную и пропущенную темы; ссылки ведут на локальные файлы примера.

## Проверка

```sh
python -B -X utf8 -m unittest discover -s tests -v
python skills/learn-start/scripts/project_state.py validate /path/to/course
python skills/learn-start/scripts/project_state.py report /path/to/course --as-of 2026-11-05
```

Валидатор проверяет структуру, ссылки, даты, предпосылки и файлы свидетельств. Он не доказывает правильность урока или оценки ответа. [Результаты проверок](evals/RESULTS.md) и [сценарии](evals/scenarios.md) описывают проверенные возможности и ограничения.
