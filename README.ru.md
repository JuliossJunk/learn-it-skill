# Learn It

Пять скиллов для самостоятельного обучения с сохранением цели, плана, попыток и точного места остановки между занятиями.

[English README](README.md) · [Лицензия MIT](LICENSE)

## Быстрая установка

Поддерживаются Codex, Claude Code, Cursor, GitHub Copilot и OpenCode. Если установлены Node.js 22.20+ и Git:

```sh
npx skills add JuliossJunk/learn-it-skill --skill '*' --agent codex --global
```

Замените `codex` на `claude-code`, `cursor`, `github-copilot` или `opencode`. Без `--global` комплект устанавливается в текущий проект. Сохраняйте `--skill '*'`: всем пяти скиллам нужны общие файлы. Команда использует сторонний [Skills CLI](https://github.com/vercel-labs/skills).

Есть и собственный установщик на Python без сторонних зависимостей. [Полная инструкция на английском](docs/installation.md) содержит пути для всех агентов, обновление, удаление, диагностику и готовый текст для установки через самого агента.

| Скилл | Пример запроса | Результат |
| --- | --- | --- |
| `learn-start` | `$learn-start Хочу изучить теорию вероятностей` | Интервью, диагностика, источники, план и файлы курса |
| `learn-progress` | `$learn-progress Где мы остановились?` | Краткий обзор результатов, пробелов и следующего шага без изменения курса |
| `learn-next` | `$learn-next Продолжим обучение` | Возврат к незавершённому заданию или подготовка следующей темы |
| `learn-test` | `$learn-test Проверь меня по изученному` | Задания, оценка реальных ответов и учёт подсказок |
| `learn-review` | `$learn-review Сделай HTML-отчёт об обучении` | Красивый автономный отчёт: все темы, история, динамика, рост и повторения |

Инструкции и названия скиллов в меню написаны на английском. Занятия, обратная связь и весь HTML-отчёт по умолчанию следуют языку общения пользователя: сначала явное предпочтение, затем язык из профиля, затем язык текущего запроса. Это касается заголовков, подписей графиков и выводов. При изучении языков изучаемый язык и язык объяснений учитываются отдельно. Скиллы также могут выбираться по смыслу запроса. Они не работают в фоне.

## Как устроен курс

Перед планом предлагается мини-тест: обычно 3–5 адаптивных заданий по одному. Агент объясняет, как ответы влияют на стартовую тему, глубину, темп и практику, и что меняется при выборе альтернативы. Каждый урок начинается со списка проверяемых компетенций и полноценной теории с авторитетными источниками. Весь материал сохраняется в Markdown, ссылка на файл даётся в чате. Для нескольких уроков раздела создаются отдельные файлы и оглавление. Практика начинается после готовности пользователя. Правильный ответ сопровождается коротким объяснением; исправления и уточнения нужны только для существенных ошибок и неоднозначностей.

Каждый курс хранится в отдельной папке. `GOAL.md` задаёт цель, `PROFILE.md` — исходный уровень и ограничения, `PLAN.md` — маршрут и предпосылки, `SOURCES.md` — материалы. `RESUME.md` сохраняет точное место остановки, `state.json` — структурированный прогресс. Материалы разделов находятся в `sections/`, история — в `sessions/`, проверки — в `assessments/`, HTML-отчёты — в `reports/`.

Пройденный материал, самостоятельное применение и удержание после перерыва учитываются отдельно. Решение с подсказкой остаётся решением с подсказкой; пропуск темы не становится успешной проверкой. Старые Markdown-проекты поддерживаются без сброса истории. Первый раздел готовится подробно, следующие раскрываются по мере продвижения.

Перед стартом `learn-start` показывает черновик плана и ждёт явного утверждения. До него можно проводить интервью, диагностику и искать источники, но нельзя создавать файлы курса или начинать уроки. Базовый уровень обосновывается проверенными стандартами, учебными программами или рекомендациями с прямыми ссылками. Если общего стандарта нет, агент прямо это сообщает. Неочевидные дополнительные темы предлагаются отдельным необязательным блоком с пользой, предпосылками и дополнительными затратами времени. Отказ от них не мешает завершить основной курс.

## Установка из локальной копии

```sh
git clone https://github.com/JuliossJunk/learn-it-skill.git
cd learn-it-skill
python scripts/install.py install --agent codex
python scripts/install.py check --agent codex
```

По умолчанию установка действует для пользователя. Выберите ID своего агента. Для отдельного проекта:

```sh
python scripts/install.py install --agent opencode --scope project --project /path/to/course
```

Предпросмотр: `install --dry-run`; обновление неизменённой управляемой установки: `install --update`; удаление: `uninstall`. Во всех случаях передавайте тот же `--agent`, а для проекта — также `--scope project --project /path/to/course`. Локальные правки и конфликтующие скиллы не перезаписываются. После получения свежей версии репозитория установщик можно запустить повторно с `--update`.

Для установки через агента можно отправить ему:

> Установи полный комплект Learn It из https://github.com/JuliossJunk/learn-it-skill для текущего coding agent на уровне пользователя. Прочитай docs/installation.md, используй встроенный Python-установщик с подходящим ID агента, сначала проверь dry run. Сохрани существующие правки, установи все пять скиллов, выполни check и сообщи, как вызвать learn-start. Курс пока не начинай.

В Codex начало курса вызывается через `$learn-start`, в Claude Code и Cursor — через `/learn-start`. В Copilot и OpenCode можно попросить обычным текстом использовать скилл `learn-start`. Язык занятий и отчётов следует вашим предпочтениям. Если новый скилл не виден, перезагрузите сессию агента и проверьте установку согласно инструкции.

Для установщика и остальных Python-скриптов нужен Python 3.10+, сторонние библиотеки не требуются. Если Python вызывается как `python3` или `py -3`, замените команду в примерах. Интервью, обучение, подбор источников и оценку открытых ответов выполняет агент.

## HTML-отчёты

В папке курса попросите `$learn-review` подготовить отчёт. Он покажет все темы, текущую точку, что ещё предстоит пройти, историю попыток, помощь, ошибки и запланированные повторения. Отчёт работает без интернета, адаптируется к узкому экрану и позволяет раскрывать разделы.

Для проекта со `state.json` можно запустить генератор из корня репозитория:

```sh
python skills/learn-review/scripts/render_review.py /path/to/course --output /path/to/course/reports/review.html --as-of 2026-11-05
```

Укажите фактическую локальную дату пользователя. Без `--as-of` повторения отображаются без пометки о просрочке. Дата ограничивает попытки, но не восстанавливает прошлое состояние учебного плана. Выбирайте новое имя для каждого отчёта. Сам скрипт создаёт английскую визуальную основу; скилл полностью переводит готовый отчёт на выбранный язык, читает исходные попытки и добавляет содержательный вывод. Старый Markdown-курс агент анализирует напрямую, без миграции.

График показывает накопление результатов с самостоятельными успешными попытками. Его рост сам по себе не доказывает улучшения знаний. Скилл проверяет сопоставимость задач, подсказки и критерии оценки. Если данных недостаточно, отчёт прямо это сообщает. Общая вероятность освоения предмета не вычисляется. Отчёты сохраняются локально; публикация требует отдельного запроса.

Для просмотра оформления на явно вымышленных данных выберите новую папку:

```sh
python examples/make_demo.py /path/to/new-demo
```

Откройте `reports/review.html` внутри неё. Пример содержит пройденную, текущую, запланированную и пропущенную темы; ссылки ведут на локальные файлы примера.

## Проверка

```sh
python -B -X utf8 -m unittest discover -s tests -v
python skills/learn-start/scripts/project_state.py validate /path/to/course
python skills/learn-start/scripts/project_state.py report /path/to/course --as-of 2026-11-05
```

Валидатор проверяет структуру, ссылки, даты, предпосылки и файлы свидетельств. Он не доказывает правильность урока или оценки ответа. [Результаты проверок](evals/RESULTS.md) и [сценарии](evals/scenarios.md) описывают проверенные возможности и ограничения.
