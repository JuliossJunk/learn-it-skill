# Check understanding

Read the sibling [shared project contract](../learn-start/references/project-contract.md). Inspect studied outcomes, previous attempts and review needs. The scope is learned material unless the learner explicitly requests a diagnostic or an unfamiliar challenge.

## Set up the check

Infer a short formative quiz for “quiz me”. Clarify only consequential missing choices, such as a broad exam's scope, time or permitted tools. State the scope and feedback mode. In practice mode, feedback follows each answer; in exam mode, agree when feedback will arrive. Match length to the available time.

Build tasks against named outcomes before asking them. Include a suitable mix of recall, explanation, execution, error diagnosis and transfer; a recognition-only quiz is insufficient for a goal of independent problem solving. Prefer new examples over the exact exercises just rehearsed. Include a delayed check when appropriate. Prepare the expected result and a short rubric before grading; verify arithmetic or executable outputs independently when useful.

For interactive checks, normally present one task at a time, with a manageable batch when items are independent or the learner prefers it. Keep solutions out of the question and learner-facing assessment file until feedback is due. Ask for reasoning when it changes the diagnosis. A learner can answer “I don't know” or stop without fabricated responses for the remaining items.

## Grade evidence

Save the actual answer and reasoning. Distinguish correct method with a slip, partial reasoning, conceptual error, ambiguity, and no attempt. If interpretation is uncertain, ask a narrow clarifying question before marking it wrong. Check that the answer refers to the same function, conditions, units and task version as the rubric.

Explain the judgement and point to the relevant step. Graduated hints may support learning, but label the resulting attempt as assisted. A revealed solution is not an independent pass. Record the assessor as model or deterministic as appropriate, and preserve user corrections if a judgement is challenged. Confidence is informative but not a score.

Use named outcomes and the shared evidence format. A reported numerical score needs an explicit rubric and denominator; do not convert a few correct items into a probability of broad mastery. Describe delayed retention only when a later attempt actually supports it.

## Close

Summarize independently demonstrated outcomes, assistance needed, and the next remediation or review. Record unfinished items as pending, not failed or completed. Save the assessment and update objective evidence, reviews and the resume note; validate state. Recommend a next section only when its prerequisites are supported, while preserving the learner's ability to choose another route.
