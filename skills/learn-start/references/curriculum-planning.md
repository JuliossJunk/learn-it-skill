# Baseline and extension planning

Use this reference when proposing or substantially redesigning a curriculum. The plan is a proposal until the learner approves it under the gate in `SKILL.md`.

## Explain the baseline

Recommend a recognizable foundation for the intended goal and context: introductory literacy, practical independent use, academic preparation, or another clearly described level. Define observable capabilities and limits rather than calling an arbitrary topic list “standard mastery.” Adapt the starting point using the diagnostic and time budget; make any compromise visible.

Find and inspect authoritative sources relevant to that level: published standards or competency frameworks, institutional curricula, professional guidance, or established primary learning materials. Verify versions and actual contents before relying on them. Prefer sources suited to the learner's use case; an advanced professional standard is not automatically a beginner's syllabus.

Explain the convention explicitly in learner-facing language: what is commonly expected at this level, who describes it, and which part of the proposed route it supports. Cite direct source locations and map the main topic groups to them. Distinguish a formal standard from a recommended practice, an example curriculum, and the agent's own synthesis. Familiarity with a source title alone is insufficient evidence of alignment.

When no shared standard exists, say so. Describe the baseline as a reasoned recommendation supported by named sources, not a universal consensus. Preserve material disagreements between sources and explain the choice. If access or verification is unavailable, label the rationale provisional and the exact uncertainty; never invent a citation or claim verified alignment. Offer an accessible alternative or ask for necessary material before finalizing that aspect of the plan.

Formal alignment claims must stay within the source's actual scope. Completing a suggested route does not confer accreditation, certification, or professional qualification.

## Offer less obvious extensions

Add a separate, optional block beyond the baseline. Choose extensions because they help this learner: connections to adjacent fields, overlooked assumptions, failure modes, alternative methods, or deeper applications. Avoid padding the plan with an arbitrary number of advanced topics.

For each extension, provide:

- The topic and its connection to the learner's goal.
- The concrete benefit or problem it helps solve, and why it lies beyond the baseline.
- Required foundations and an appropriate point to revisit it.
- Additional effort and a credible resource or a clearly labelled resource gap.

Keep extensions outside the core requirements, exit checks, and core time estimate until selected. A prerequisite needed to achieve the core outcomes belongs in the baseline, even if learners often overlook it. An optional extension that the learner declines is not an evidence gap or an obstacle to completing the agreed course.

Present extension choices before requesting plan approval. Record selected and deferred options in the accepted plan so later lessons and reports preserve the distinction. Obtain approval before adding deferred extensions to the route or increasing its agreed scope.
