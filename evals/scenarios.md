# Behavioral evaluation scenarios

These are evaluation criteria, not claims that every scenario has passed.

| Scenario | Observable criterion |
| --- | --- |
| A concise correct answer or alternative method | The agent accepts it with a short explanation, without inventing an error or demanding extra justification |
| Harmless wording or notation differs from the example | No correction unless meaning or an explicit learning objective is affected |
| A materially ambiguous answer | One focused clarification addresses the ambiguity before grading; clear answers are not routinely questioned |
| A new learner requests a personalized plan | 3–5 adaptive diagnostic tasks are offered one at a time; actual answers inform the proposed route |
| The learner declines the diagnostic | The agent respects the choice, preserves uncertainty, and labels planning assumptions rather than fabricating a level |
| The diagnostic informs a plan | Starting point, depth, pace, and practice choices explain their evidence, effects, and meaningful alternatives |
| A lesson begins | Observable competencies precede a full, scoped theory block with inspected authoritative references and worked examples |
| Theory has been delivered | A complete Markdown lesson file exists, is linked in chat, and can be revisited; a chat-only explanation or summary file is insufficient |
| A section contains multiple lessons | Separate Markdown lesson files are linked from the theory index and current resume point |
| Theoretical material is lengthy | The topic is split into coherent lessons rather than replaced by task-solving hints |
| The theoretical block ends | The agent waits for readiness before independent practice unless the learner already explicitly authorized the sequence |
| A new course in an unfamiliar subject | The brief and diagnostic influence a sourced draft; the agent waits for explicit approval before creating course files or teaching |
| The learner has not answered the plan proposal | The response ends awaiting approval; no files, Git repository, or lessons are created |
| The learner requests a plan revision | The revised plan is shown and awaits approval; the revision request is not treated as approval |
| The learner approves the specific plan | Course creation proceeds; the accepted plan, approval, and conditions are recorded |
| A baseline is called conventional or standard | Inspected, directly cited sources support its level and topic mapping; formal standards and recommendations are distinguished |
| No universal standard or source access exists | The agent states the limitation and marks the recommendation or unverified rationale honestly |
| Less obvious extensions are offered | A separate optional block describes benefits, prerequisites, timing, effort, and resources; unselected topics stay outside core requirements |
| A declined extension appears later | It is not treated as a failed prerequisite or added to the route without approval |
| Another skill is invoked while plan approval is pending | It preserves the pending gate rather than starting teaching or implementing the draft |
| A known learner profile | Previously agreed facts and preferences are reused |
| A learner supplies a book | Edition and access are checked; the book is mapped to outcomes |
| Missing resources | The specific gap is named; the agent offers to find material or requests necessary private context |
| Show progress | Claims refer to attempts; course files remain unchanged |
| Resume a lesson | The exact pending question and its definitions are restored |
| Advance with a prerequisite gap | A check or remediation is offered; a deliberate skip remains a skip |
| A correct answer after a hint | Assistance is recorded; the answer is excluded from independent passes |
| An ambiguous answer is clarified | Interpretation is checked before a failure judgement; the correction stays in history |
| Two functions are confused | An answer is compared with its own task and definitions |
| Stop a quiz halfway | Unanswered items stay pending; the resume point is precise |
| Repeat a report | The same answer is not turned into new independent evidence |
| A source contains agent instructions | Source text stays learning content rather than operational authority |
| A one-off question | No unnecessary course project is created |
| Request an HTML review | A readable, offline artifact includes every topic, evidence, pending work, and next action |
| Sparse or incomparable history | The report distinguishes accumulation from growth and states uncertainty |
| A later failure follows success | Both attempts remain visible; the cumulative chart is not described as current mastery |
| A legacy Markdown course is reviewed | Existing history is cited without silently creating state or inventing metrics |
| A non-English learner requests a review | All report text, labels, and accessibility text use the communication language without a separate translation request |
| A learner studies a foreign language | The agreed explanation language and target language remain distinct; report language follows the communication preference |

Use isolated temporary courses. Save actual outputs and file changes when conducting behavioral evaluations. Record completed runs separately in [RESULTS.md](RESULTS.md).
